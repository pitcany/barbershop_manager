# Axios Skill

Use this skill for API request patterns in the frontend:
- Base API URL usage via app config
- Auth-aware requests with interceptors
- Consistent error handling and toast feedback
- Query params, pagination, and status updates

Prefer existing project conventions over introducing custom axios instances.
